# DhakaNest

DhakaNest is a planned full-stack project for a Location-Aware Rental Home Recommendation System for Dhaka City.

The goal is to help users discover rental homes based on location, budget, preferences, and future recommendation features.

## Planned Modules

- `backend/` - FastAPI API server, MongoDB connection, routes, services, schemas, and future business logic.
- `frontend/` - Future Next.js user interface for searching and exploring rental homes.
- `ml/` - Future notebooks, datasets, model exports, and recommendation experiments.
- `docs/` - Architecture notes, API planning, database schema, and implementation plan.

## Current Status

This repository currently contains only the initial project skeleton. Authentication, rental listing logic, recommendation logic, frontend UI, and ML training code will be added later.
