# DhakaNest Backend

This folder contains the FastAPI backend for DhakaNest.

## What Exists Now

- A basic FastAPI app entry point.
- A `/health` endpoint for checking that the API is alive.
- Environment-based configuration using `pydantic-settings`.
- MongoDB connection setup using Motor.

## What Will Be Added Later

- Authentication.
- Rental listing APIs.
- Recommendation APIs.
- Database models and schemas.
- Business services and utility helpers.

## Local Setup Later

Install dependencies and run the server only when you are ready to start backend development.
