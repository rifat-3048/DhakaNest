# Phase 3 Prebenchmark Amendment

Effective reference: original Phase 1 protocol **1.0.0** plus the adjacent
amendment **1.1.0-phase3**. Original files and manifests remain unchanged.
The user authorized this work in the Phase 3 brief. Supervisor approval has
not been provided and is not claimed. Refinements precede benchmark generation
and comparative outcome examination.

A. Add `B_JOURNEY_INSPIRED`, a future independent journey-aware Pareto comparison
informed by literature registry P04 and P31. Available evidence does not permit
claiming faithful reproduction of either original implementation. Development
tie rules must be frozen before held-out comparisons.

B. Add `A_SINGLE_DESTINATION`: retain the highest-importance destination, with
original input order resolving ties. One-destination profiles cannot distinguish
this condition. This phase specifies but does not implement either experiment.

C. Use a common, diverse, deterministically sampled annotation pool, not only
the proposed method's Top-K. Reserve pair-deduplicated union of future baseline
nominations. Pooled judgments do not establish exhaustive inventory relevance;
report unjudged rates and perform prespecified sensitivity analysis later.

D. Blind algorithm identity, rank, scores, explanations, nominations, and model
rent assessment. Collect independent human labels without looking at final
comparative outcomes. No labels are created in Phase 3.

Additional safeguards distinguish location-criterion removal on a fixed eligible
pool from an end-to-end no-routing condition. Area-first comparisons start with
their declared candidate universe, never with the proposed KNN-selected set.
Sparse profiles remain as measured coverage cases; they are not manufactured
into competitive Top-10 tasks.
