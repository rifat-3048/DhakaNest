# Architecture

DhakaNest will be organized as a full-stack application with separate backend, frontend, machine learning, and documentation areas.

## Planned Components

- FastAPI backend for API endpoints and database access.
- MongoDB database for rental listing and user preference data.
- Next.js frontend for the user-facing rental search experience.
- ML module for future recommendation experiments and exported artifacts.

This document will be expanded as implementation decisions are made.
