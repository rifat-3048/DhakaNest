# Local Submission Checklist

- [ ] Real secrets remain only in ignored local environment files
- [ ] Local MongoDB Server is running
- [ ] Required indexes pass read-only verification
- [ ] XGBoost model bundle loads
- [ ] Configured OSRM provider is reachable
- [ ] Backend `/health` and `/ready` pass
- [ ] Backend and frontend automated tests pass
- [ ] TypeScript, ESLint, and normal Next.js build pass
- [ ] Recommendation evaluation matches the documented final run
- [ ] Tenant results, map, and history are demonstrated locally
- [ ] Landlord listing and admin review flows are demonstrated locally
- [ ] Required screenshots are captured without secrets
- [ ] Technical report and presentation use the final facts
- [ ] Submission package excludes caches, dependencies, logs, and secrets

Docker, container images, cloud hosting, HTTPS proxy setup, and hosted rollback
procedures are not required for this local academic project.
