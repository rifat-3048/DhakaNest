# Manual Examiner Demo Checklist

- [ ] Start MongoDB, backend, and frontend; open `/health`, `/ready`, and `/docs`.
- [ ] Log in as a landlord and show owned listings.
- [ ] Create or open a development draft and show property data, coordinates, and images.
- [ ] Submit a complete development listing for review.
- [ ] Log in as admin; show rent assessment and approve/request revision/reject rules.
- [ ] Show that an approved listing is available and recommendation-eligible.
- [ ] Log in as tenant; enter housing needs without choosing a residential area.
- [ ] Add 1-3 resolved destinations, importance, optional commute, and priorities.
- [ ] Generate recommendations and show loading, ranks, reasons, and five scores.
- [ ] Select cards/markers and show traffic-free route lines and saved commute metrics.
- [ ] Open recommendation history and a historical immutable result.
- [ ] Mark a disposable approved listing rented and show it is no longer eligible.
- [ ] Show final evaluation and automated test evidence.

Use disposable development records. Keep account passwords in ignored local
notes, never in this tracked checklist.
